# IB Personal Project – Python Game Development

## Overview
This project was developed as part of my IB Middle Years Programme (MYP) Personal Project. The goal was to learn game development using Python and create a functional video game using the Pygame library.

## Technologies Used
- Python
- Pygame
- Visual Studio Code

## What I Learned
- Python programming fundamentals
- Game development concepts
- Event handling and user input
- Debugging and troubleshooting
- Project planning and iterative development

## Features
- Player movement and controls
- Interactive gameplay mechanics
- Score/game state management
- Custom game logic built in Python

## Project Notes
This repository contains the source code used for the project. Some game assets (images, sounds, and other media files) are not included in this repository. As a result, the project may require additional assets to run exactly as originally developed.

## Purpose
This project was completed to explore programming, problem-solving, and software development through the creation of a playable game. It served as an introduction to larger coding projects and strengthened my interest in technology and computer science.
